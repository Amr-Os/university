## Project Description

This project is a College Management System developed using Java and Object-Oriented Programming concepts.

The system includes management of students, staff, departments, classrooms, library, auditorium, bus, canteen, hostel, and parking.

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Inheritance
- Association
- Aggregation
- Composition
- Method Overloading
