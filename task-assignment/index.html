☁️ ذاكرة الفريق — ملف واحد فقط

ملف واحد مشترك: task-assignment/progress.json — والموقع نفسه يعيد كتابته تلقائياً. الخطوات:

  1. اضغط «📂 ربط ملف الذاكرة» بالأعلى واختر ملف progress.json من مجلد الموقع (مرة واحدة فقط).
  2. علّم على مهامك — الموقع يعيد كتابة الملف تلقائياً بعد كل تعليم.
  3. نفّذ: git add task-assignment/progress.json ثم git commit -m "progress" ثم git push.
  4. زملاؤك ينفّذون git pull ويحدّثون الصفحة — فيرون شارات ✓ ١ / ٢ / ٣ على كل مهمة منجزة، وسطر «المدفوع» في كل بطاقة.

متصفحك لا يدعم الربط المباشر؟ اضغط «💾 حفظ في الملف» لتنزيل نسخة محدثة من progress.json، ضعها مكان الملف القديم، ثم push.
